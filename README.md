# Spotify Song Popularity Prediction

## Project Overview

This project investigates the relationship between Spotify audio features, release year, and song popularity using statistical and machine learning methods.

The analysis uses the **Spotify Dataset 1921–2020**, with song popularity (`popularity`) as the target variable.

Two feature groups are compared:

- **Group A – Audio Features:** Uses audio-related variables to predict song popularity.
- **Group B – Audio Features + Year:** Adds release year to evaluate whether temporal information improves prediction performance.

The project implements data auditing, preprocessing, regression analysis, model evaluation, statistical inference, model diagnostics, and prediction error analysis.

## Dataset

The main input file is:

```text
Dataset/data.csv
```

The dataset contains Spotify track information and audio features, including:

- Danceability
- Energy
- Loudness
- Acousticness
- Instrumentalness
- Liveness
- Speechiness
- Valence
- Tempo
- Duration
- Explicit
- Key
- Mode
- Release year
- Popularity

The target variable is `popularity`, ranging from 0 to 100.

The dataset is not generated by the scripts. Place the original dataset in the `Dataset` directory before running the analysis.

## Analysis Workflow

Run the scripts in the following order.

| Script | Description |
|---|---|
| `01_data_audit.py` | Examines data structure, missing values, duplicates, descriptive statistics, and data quality. |
| `02_data_preprocessing.py` | Selects variables, handles invalid values, transforms duration, and generates the modeling dataset. |
| `03_model_training.py` | Trains and evaluates the baseline, OLS, Ridge, and Lasso regression models. |
| `04_ols_inference.py` | Performs OLS statistical inference using robust standard errors. |
| `05_vif_analysis.py` | Evaluates multicollinearity using Variance Inflation Factors (VIF). |
| `06_model_diagnostics.py` | Examines regression residuals, heteroscedasticity, and residual normality. |
| `07_prediction_error_analysis.py` | Analyzes prediction errors across popularity levels and release periods. |
| `08_nonlinear_model_comparison.py` | Compares Random Forest and HistGradientBoosting models and calculates feature importance. |

## Models

The project evaluates the following models:

**Linear models**
- Mean baseline
- Ordinary Least Squares (OLS)
- Ridge Regression
- Lasso Regression

**Nonlinear models**
- Random Forest Regressor
- HistGradientBoosting Regressor

Model performance is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## Notes

- Preprocessing and model fitting are performed using training data to reduce data leakage.
- The same random train-test split is used for model comparisons.
- Release year is evaluated as an additional predictive variable.
- Feature importance and regression coefficients describe model associations and predictive contributions; they should not be interpreted as causal effects.
- Results may vary if the dataset, preprocessing procedures, or model parameters are changed.
